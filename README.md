# 宇宙无限银行 · 财富显化支票

基于 Next.js 的免登录支票制作网页，可部署到 Vercel。

- 打开网页直接填写日期、收款人、金额、用于/目标和填写人。
- 五项验证通过并提交后，可以下载 PNG 或 JPG 高清图片。
- 每个浏览器有 50 次提交机会，填写错误也计入；重复下载不计次。
- 浏览器 IndexedDB 事务保存次数与最近成功支票，多标签同时提交也不会超过 50 次。
- 刷新页面保留记录；清除网站数据、更换浏览器或使用新的隐私窗口会重新计数。免登录模式无法限制同一个自然人在不同浏览器中的总次数。
- 内容仅保存在当前浏览器，不上传到账号数据库；之前账号中的记录不会自动迁移。

## 本地运行

使用 Node.js 22.13 或更高版本：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:3000/。免登录填写不需要配置环境变量或数据库。

## 部署

将仓库导入 Vercel，选择 Next.js，运行 npm run build。生产主页不访问登录服务。

## 验证

```sh
npm test
npm run build
```

核心文件：app/checkbook.tsx（填写、预览、导出）、lib/browser-checks.ts（浏览器事务计数）、lib/checks.ts（字段验证）、public/check-template.jpg（原始支票底图）。历史账号接口和数据库迁移保留，但免登录主页不使用它们。
